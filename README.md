## 7. Como funciona a integração

Explique de forma objetiva e em até 10 passos como sua aplicação se comunica com a API.

1. Usa o link (endereço) para declarar a constante.
2. Ao clicar no botão de carregar mais ele dispara a função de comunicação.
3. As variáveis gerenciam o limite de personegens e em qual página você está.
4. A função "endpoint" junta a url com base no HTTPS.
5. O comando fetch faz com que a API nao dependa do servidor para rodar.
6. A resposta da API fica mais legível.
7. A Função "array" lê um personagem por vez.
8. Cada chaves está pegando apenas nome e foto dos personagens.
9. As funções "cards" estão fazendo o trabalho de criar cada campo para cada personagem.
10. A aplicação incrementa o número da página e reabilita a interface para permitir a próxima chamada à API.
